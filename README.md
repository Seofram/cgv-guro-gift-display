# CGV 구로 경품 안내

Windows 듀얼 모니터 환경을 위한 로컬 경품 안내 전시 시스템입니다. 관리 화면에서
영화·경품·재고 정보를 수정하면 두 번째 모니터의 1280×1024 전시 화면에 자동으로
반영됩니다.

## 주요 기능

- 영화명, 관람 포맷, 경품명, 재고 현황 관리
- 날짜와 표시 요일에 따른 자동 노출
- 제공 중, 소진 중, 소진 임박, 재고 소진, 준비 중 상태 표시
- 8행 초과 시 자동 페이지 전환
- 긴 문구 최대 두 줄 표시
- 주의사항 추가·수정·삭제
- 두 번째 모니터 전체화면 및 항상 위 전시
- 전시 연결 상태 모니터링과 비정상 종료 감지
- SQLite 로컬 저장소와 데이터 초기화 도구
- Node.js 미설치 PC를 위한 공식 포터블 Node.js 자동 준비
- 나눔스퀘어 네오 글꼴 로컬 포함

## Windows에서 실행

1. [Releases](../../releases)에서 최신 ZIP 파일을 내려받아 압축을 풉니다.
2. `start-local.bat`을 더블클릭합니다.
3. 열린 관리 화면에서 `전시 화면 열기`를 누릅니다.

Node.js가 없거나 버전이 낮으면 최초 실행 시 공식 포터블 Node.js와 필요한
구성요소를 자동으로 내려받습니다. 최초 실행에는 인터넷 연결이 필요하며 관리자
권한은 필요하지 않습니다.

자세한 사용 방법은 [README_사용법.md](README_사용법.md)를 확인하세요.

## 개발

요구 Node.js 버전은 `22.13.0` 이상입니다.

```powershell
npm ci
npm run dev
npm test
```

## 데이터 저장

관리 데이터는 `%LOCALAPPDATA%\CGVGiftDisplay\inventory.db`에 저장됩니다.
데이터베이스는 최초 실행 시 자동 생성되며, 브라우저 데이터나 프로그램 폴더를
삭제해도 유지됩니다. 데이터 초기화는 `reset-data.bat`, 로컬 운영 구성까지
제거하는 경우에는 `clean-uninstall.bat`을 사용합니다.

## 글꼴 및 상표

나눔 글꼴의 저작권과 재배포 조건은
`public/fonts/LICENSE-NANUM-FONT.txt`를 확인하세요.

CGV 명칭과 로고는 해당 권리자의 상표입니다. 로고 사용 권한은 실제 운영 주체가
별도로 확인해야 합니다.
