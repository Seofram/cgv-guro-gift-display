# CGV 구로 경품 안내 — 사용 설명서

## 설치와 실행

1. 최신 Windows 설치 파일을 실행합니다.
2. 시작 메뉴에서 CGV 구로 경품 안내를 실행합니다.
3. 관리 창 오른쪽 위 전시 화면 열기를 누릅니다.
4. 전시 창은 두 번째 모니터에 전체화면·항상 위 상태로 표시됩니다.
5. 모니터링 열기는 관리 모니터에서 전시 내용을 작은 일반 창으로 엽니다.
6. 전시 종료는 두 번째 모니터의 전시 창만 닫습니다.

CMD 창, Node.js, npm, Edge 키오스크 또는 로컬 서버는 운영 시 필요하지 않습니다.

## 항목 관리

- + 항목 추가로 새 경품을 만듭니다.
- 각 행의 위·아래 화살표로 표시 순서를 바꿉니다.
- 같은 영화끼리 정렬을 누르면 영화가 처음 등장한 순서를 기준으로 같은 영화의
  경품을 모읍니다. 같은 영화 안의 경품 순서는 유지됩니다.
- 시작일·종료일과 표시 요일에 따라 오늘 전시 여부가 자동 결정됩니다.
- 전체 또는 개별 설정으로 표시 요일을 선택합니다.
- 재고 상태와 노출 여부를 변경하면 자동 저장됩니다.

## 데이터 저장과 복구

관리 데이터는 다음 SQLite 파일에 저장됩니다.

    %LOCALAPPDATA%\CGVGiftDisplay\inventory.db

업데이트 설치와 프로그램 제거는 이 파일을 삭제하지 않습니다. 초기화가 필요하면
앱을 완전히 종료하고 파일을 안전한 위치로 옮긴 뒤 앱을 다시 실행합니다. 문제가
생기면 옮겨 둔 파일을 원래 경로에 복원할 수 있습니다.

## 운영 PC 점검

최종 배치 전 다음 조건을 확인합니다.

1. Windows 디스플레이 설정에서 화면이 확장으로 설정되어 있습니다.
2. 기존 inventory.db가 위 경로에 있습니다.
3. 실행 중인 CGV 경품 안내 앱을 모두 종료합니다.
4. 저장소 폴더에서 다음 명령을 실행합니다.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-desktop-install.ps1 -ApplicationPath "설치된 cgv-guro-gift-display.exe의 전체 경로"

도구가 관리 창에 기존 데이터가 보이는지 물으면 화면을 확인한 뒤 Y를 입력합니다.
자동 검사까지 통과하면 다음 파일이 생성됩니다.

- inventory.pre-desktop-verification-*.bak: 실행 전 DB 백업
- desktop-verification-*.json: 설치 크기, 실행 속도, 모니터 및 창 위치 결과

보고서의 Status가 passed, ExistingDataConfirmedByOperator가 true,
DisplayFullscreen이 true, WarmStartupMilliseconds가 2000 이하여야 최종 검증을
통과한 것입니다.

## 문제 해결

- 전시 창이 잘못된 화면에 열리면 Windows 디스플레이 설정에서 주 모니터를
  확인하고 앱을 다시 실행합니다.
- 설치 직후 첫 실행은 WebView2 준비 때문에 일반 재실행보다 오래 걸릴 수 있습니다.
- 기존 데이터가 보이지 않으면 앱을 종료하고 데이터베이스 경로를 확인합니다.
- 검증 전 백업 파일은 확인이 끝날 때까지 삭제하지 마세요.

나눔 글꼴은 앱에 포함되어 오프라인 환경에서도 동일하게 표시됩니다.
