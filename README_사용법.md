# CGV 구로 경품 안내 — 사용 설명서

사진으로 전달받은 기존 PPT 구성을 바탕으로 만든 관리·전시 화면입니다.

## 포함된 기능

- 영화명, 관람 포맷, 경품명, 재고 현황 관리
- 시작일·종료일·표시 요일에 따른 자동 노출
- 관리 화면에 오늘 날짜·요일과 실제 노출 상태 표시
- 만료, 시작 전, 오늘 제외 항목을 행 색상과 상태표로 구분
- 제공 중, 소진 중, 소진 임박, 재고 소진, 준비 중 상태별 색상
- 재고 상태의 긴급도에 따른 전시 화면 점등 효과
- 표시 요일은 전체가 기본이며 필요한 항목만 개별 요일 설정
- 유효 기간이 지난 항목의 일괄 삭제 안내
- 같은 영화의 여러 경품을 전시 화면에서 자동으로 묶어서 표시
- 영화명·관람 포맷·경품명이 길면 최대 두 줄로 자동 표시
- 8행 초과 시 페이지 자동 전환
- 하단 주의사항 추가·수정·삭제
- 관리 화면의 수정 사항을 전시 화면에 자동 반영
- SQLite 로컬 저장소에 운영 데이터 자동 보관
- Edge 키오스크와 관리 화면 사이의 로컬 데이터 자동 동기화
- 관리 화면에서 전시 연결 상태와 마지막 동기화 시각 확인
- 전시 창 비정상 종료 감지 및 재실행 안내
- 1280×1024 전시 디스플레이 최적화
- 네이버 나눔스퀘어 네오 로컬 웹폰트 적용

## 실행 방법

1. 압축을 풀고 `start-local.bat`을 더블클릭합니다.
2. Node.js가 없거나 버전이 낮으면 공식 휴대용 Node.js를 자동으로 준비합니다.
   별도의 설치 화면이나 관리자 권한은 필요하지 않습니다.
3. 처음 실행할 때만 Node.js와 필요한 구성요소를 내려받으므로 인터넷 연결이 필요합니다.
   평소에는 실행 준비가 끝나면 CMD 창이 자동으로 닫힙니다.
4. 열린 관리 화면에서 오른쪽 위 `전시 화면 열기`를 누릅니다.
5. 전시 창은 두 번째 모니터에 전체화면·항상 위 상태로 자동 표시됩니다.
6. `모니터링 열기`는 관리 모니터에서 전시 내용을 작은 일반 창으로 확인합니다.
7. `전시 종료`를 누르면 두 번째 모니터의 전시 전용 창만 닫힙니다.

관리 데이터는 `%LOCALAPPDATA%\CGVGiftDisplay\inventory.db` SQLite 파일에
저장됩니다. 최초 실행 시 자동으로 생성되며 브라우저 데이터 삭제나 프로그램 ZIP
교체의 영향을 받지 않습니다. 이전 버전의 브라우저 데이터는 데이터베이스가 비어
있을 때 한 번 자동으로 이전됩니다.

영화, 경품, 재고, 주의사항 데이터를 모두 제거하려면 프로그램 폴더의
`reset-data.bat`을 실행하고 화면 안내에 따라 `초기화`를 입력합니다. 실행 중인
전시 화면과 로컬 서버가 종료되며, 다시 사용할 때는 `start-local.bat`을 실행합니다.

프로그램 사용을 중단하면서 로컬 DB, 로그, 포터블 Node.js, 설치된 구성요소와
빌드 캐시까지 제거하려면 `clean-uninstall.bat`을 실행하고 `제거`를 입력합니다.
프로그램 소스 폴더는 확인을 위해 남으므로 완료 후 직접 삭제할 수 있습니다.

자동 전시 제어 기능을 사용하려면 반드시 `start-local.bat`으로 실행해 주세요.
실행할 때 이전에 남아 있는 전시 제어 프로그램은 자동으로 새 버전으로 교체됩니다.
Windows 보안 화면이나 다른 항상 위 프로그램은 전시 화면 위에 표시될 수 있습니다.

## 운영 환경

제공받은 투명 CGV 로고 이미지를 사용하며, 듀얼 모니터 Windows PC에서
두 번째 모니터를 전시 화면으로 사용하는 구성을 기준으로 합니다.
