# CGV 구로 경품 안내 — 사용 설명서

## 준비와 실행

1. Windows x64 ZIP을 원하는 폴더에 완전히 압축 해제합니다.
2. PC에 Microsoft Edge 또는 Google Chrome이 설치되어 있는지 확인합니다.
3. `start-local.bat`를 더블클릭합니다.
4. 관리 화면에서 **전시 화면 열기**를 누릅니다.
5. **모니터링 열기**는 관리 모니터에서 전시 내용을 작은 창으로 확인합니다.
6. **전시 종료**는 보조 모니터의 전시 창만 닫습니다.

실행 시 CMD 창은 곧바로 닫히며, 백그라운드에는 작은 로컬 서버 하나만 남습니다.
Node.js, npm, Tauri 설치나 인터넷 연결은 필요하지 않습니다.

## Chrome으로 변경

기본 브라우저는 Edge입니다. 패키지 폴더의 `browser-settings.json`을 메모장으로
열고 다음처럼 바꾼 뒤 다시 실행합니다.

    {
      "browser": "chrome",
      "executablePath": ""
    }

브라우저를 자동으로 찾지 못하면 `executablePath`에 `chrome.exe` 또는
`msedge.exe`의 전체 경로를 입력합니다. JSON 경로의 `\`는 `\\`로 적어야 합니다.

## 항목 관리

- **+ 항목 추가**로 새 경품을 만듭니다.
- 각 행의 위·아래 화살표로 표시 순서를 바꿉니다.
- **같은 영화끼리 정렬**은 영화가 처음 등장한 순서를 기준으로 같은 영화의 경품을
  모으며, 같은 영화 안의 경품 순서는 유지합니다.
- 시작일·종료일과 표시 요일에 따라 오늘 전시 여부가 자동 결정됩니다.
- 재고 상태와 노출 여부를 변경하면 SQLite에 자동 저장됩니다.

## 데이터와 업데이트

운영 데이터 위치:

    %LOCALAPPDATA%\CGVGiftDisplay\inventory.db

새 릴리즈로 업데이트할 때는 기존 패키지 폴더 대신 새 ZIP을 별도 폴더에 풀어
`start-local.bat`를 실행하면 됩니다. 위 데이터 파일은 그대로 이어서 사용합니다.
중요한 변경 전에는 `inventory.db`와 같은 폴더의 `-wal`, `-shm` 파일을 함께
백업하세요.

## 문제 해결

- 전시 화면이 잘못된 모니터에 열리면 Windows 디스플레이 모드를 **확장**으로
  설정하고 전시 종료 후 다시 엽니다.
- 브라우저를 찾을 수 없다는 오류는 `browser-settings.json`의 값과 경로를
  확인합니다.
- 화면이 열리지 않으면 `http://127.0.0.1:3210/health`를 브라우저에서 열어
  `"ok": true`가 보이는지 확인합니다.
- 서버 시작 오류는
  `%LOCALAPPDATA%\CGVGiftDisplay\server-error.log`에 기록됩니다.
- 데이터만 초기화하려면 `reset-data.bat`, 데이터와 전용 브라우저 프로필까지
  지우려면 `clean-uninstall.bat`를 사용합니다.

나눔 글꼴은 패키지에 포함되어 오프라인에서도 동일하게 표시됩니다.
