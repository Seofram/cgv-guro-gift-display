# CGV 구로 경품 안내 — 사용 설명서

## 준비와 실행

1. Windows x64 ZIP을 원하는 폴더에 완전히 압축 해제합니다.
2. PC에 Microsoft Edge 또는 Google Chrome이 설치되어 있는지 확인합니다.
3. `start-local.bat`를 더블클릭합니다.
4. 관리 화면에서 **전시 화면 열기**를 누릅니다.
5. **모니터링 열기**는 관리 모니터에서 전시 내용을 작은 창으로 확인합니다.
   이 창은 보기 전용이며 열어 둔 채로 데이터를 수정해도 됩니다.
6. **전시 종료**는 보조 모니터의 전시 창만 닫습니다.

실행 시 CMD 창은 곧바로 닫히며, 백그라운드에는 Windows PowerShell 로컬 서버와
이를 지켜보는 감시 프로세스가 남습니다. 서버가 예기치 않게 종료되면 감시
프로세스가 자동으로 다시 시작합니다. 별도 EXE, Node.js, npm, Tauri 설치나
인터넷 연결은 필요하지 않습니다.

PC를 다시 켠 뒤에는 `start-local.bat`를 실행하고 **전시 화면 열기**를 다시
눌러야 합니다. 전시 창이 닫혔을 때 자동으로 다시 열리지는 않으며, 관리 화면에
안내 창이 표시됩니다.

## Chrome으로 변경

기본 브라우저는 Edge입니다. 패키지 폴더의 `browser-settings.json`을 메모장으로
열고 다음처럼 바꾼 뒤 다시 실행합니다.

    {
      "browser": "chrome",
      "executablePath": ""
    }

브라우저를 자동으로 찾지 못하면 `executablePath`에 `chrome.exe` 또는
`msedge.exe`의 전체 경로를 입력합니다. JSON 경로의 `\`는 `\\`로 적어야 합니다.
새 버전으로 교체하면 이 파일은 기본값(Edge)으로 돌아가므로 다시 설정합니다.

## 항목 관리

- **+ 항목 추가**로 새 경품을 만듭니다.
- 각 행의 위·아래 화살표로 표시 순서를 바꿉니다.
- **같은 영화끼리 정렬**은 영화가 처음 등장한 순서를 기준으로 같은 영화의 경품을
  모으며, 같은 영화 안의 경품 순서는 유지합니다.
- 시작일·종료일과 표시 요일에 따라 오늘 전시 여부가 자동 결정됩니다.
- 재고 상태와 노출 여부를 변경하면 SQLite에 자동 저장됩니다.
- 항목이나 주의사항을 삭제하면 화면 아래에 **되돌리기** 버튼이 15초 동안
  나타납니다. 만료 항목 정리와 예시 데이터 초기화도 되돌릴 수 있습니다.
- **예시 데이터로 초기화**는 확인 창에서 한 번 더 확인한 뒤 실행됩니다.
  초기화 뒤 다른 내용을 수정하면 초기화 되돌리기 버튼은 사라집니다. 초기화 전
  데이터는 **보관된 버전**에서 확인하고 복원할 수 있습니다.

## 화면 위쪽의 상태 표시

| 표시 | 의미 | 할 일 |
| --- | --- | --- |
| 자동 저장 / 저장됨 | 변경 내용이 SQLite에 저장되었습니다. | 없음 |
| 저장 중… | 현재 수정 내용의 서버 저장 응답을 기다리고 있습니다. | 저장이 끝날 때까지 기다립니다. |
| 저장 실패 · 재시도 중 | 서버에 연결하지 못했습니다. 수정 내용은 이 PC에 보관되며 3초마다 다시 저장을 시도합니다. | 계속 표시되면 `start-local.bat`를 다시 실행합니다. 창을 닫았다 열어도 수정 내용은 유지됩니다. |
| 저장 충돌 · 저장 보류 | 다른 창에서 다른 내용이 먼저 저장되어 이 창의 수정 내용을 저장하지 않았습니다. | **충돌 해결**을 눌러 사용할 내용을 선택합니다. (아래 참고) |
| 전시 창 응답 중 | 서버가 연 전시 창에서 데이터 수신 응답이 도착합니다. | 보조 모니터에 실제 화면이 보이는지는 직접 확인합니다. |
| 전시 여는 중 | 전시 창의 첫 응답을 기다리고 있습니다. | 잠시 기다립니다. |
| 전시 데이터 지연 | 전시 창이 응답하지만 최신 데이터가 아직 반영되지 않았습니다. | 계속되면 전시 화면을 다시 엽니다. |
| 전시 응답 없음 | 전시 창은 있지만 화면이 15초 넘게 데이터를 받아 가지 않습니다. | 보조 모니터를 확인하고 **전시 종료** 후 **전시 화면 열기**를 누릅니다. |
| 전시 대기 | 전시 창이 열려 있지 않습니다. | 필요하면 **전시 화면 열기**를 누릅니다. |
| 제어 연결 끊김 | 관리 화면이 서버에 연결하지 못했습니다. | `start-local.bat`를 다시 실행합니다. |
| 자동 백업 실패 | 저장은 계속되지만 백업을 만들지 못했습니다. | 저장 공간·폴더 권한과 `backup-error.log`를 확인합니다. |

## 저장 충돌이 표시될 때

두 개의 관리 창(예: 서로 다른 브라우저나 오래 열어 둔 창)에서 각각 수정하면,
나중에 저장하려는 창에 **이 창의 수정 내용을 저장하지 않았습니다** 창이
나타납니다. 이때 어느 쪽 내용도 지워지거나 덮어써지지 않습니다.

- **이 창의 내용으로 저장**: 이 창의 내용을 저장합니다. 다른 창에서 저장했던
  내용은 화면 아래 **보관된 버전**에 남습니다.
- **저장된 최신 내용 사용**: 저장되어 있는 내용을 불러옵니다. 이 창에서 수정한
  내용은 **보관된 버전**에 남습니다.
- **나중에 선택**: 창을 닫고 계속 작업합니다. 선택하기 전까지 이 창의 수정
  내용은 저장되지 않고 이 PC에만 보관됩니다. 위쪽의 **충돌 해결** 버튼으로 다시
  열 수 있습니다.

**보관된 버전**의 각 항목은 **이 버전으로 복원**(현재 내용은 다시 보관됨),
**파일로 저장**, **삭제**를 할 수 있습니다. 직접 삭제하기 전까지 남아 있으며
최근 20개까지 보관합니다. 보관된 버전은 관리 화면용 브라우저 프로필에 저장되므로
`clean-uninstall.bat`를 실행하면 함께 지워집니다.

## 데이터와 백업

운영 데이터 위치:

    %LOCALAPPDATA%\CGVGiftDisplay\inventory.db

일일 백업 위치:

    %LOCALAPPDATA%\CGVGiftDisplay\backups\inventory-YYYYMMDD.db

- 매일 그날 처음 데이터를 변경하기 직전의 상태가 자동으로 백업됩니다.
- 처음 저장한 새 데이터도 백업합니다. 백업에 실패하면 관리 화면에 표시됩니다.
- 백업은 단독으로 열 수 있는 SQLite 파일 하나이며, 최근 14일분을 보관합니다.
- `reset-data.bat`는 백업 폴더를 지우지 않습니다. `clean-uninstall.bat`는 백업을
  포함한 모든 운영 데이터를 지웁니다.
- `reset-data.bat`는 삭제 직전의 데이터를 `pre-reset-날짜-시간.db`로 별도 백업하고
  정상적으로 읽히는지 확인합니다. 백업에 실패하면 초기화를 중단하고 현재 데이터를
  남깁니다. 초기화 전 백업은 일일 백업 14개 정리 대상에 포함되지 않습니다.

### 백업에서 복원하기

1. 관리 창과 전시 창을 모두 닫습니다.
2. 패키지 폴더의 `reset-data.bat`를 실행하고 `초기화`를 입력합니다. (서버를
   종료하고 현재 데이터를 검증된 별도 백업으로 남긴 뒤 지웁니다. 백업에 실패하면
   중단됩니다. 실패한 상태에서 파일을 지우지 말고 담당자에게 문의합니다.)
3. `backups` 폴더에서 복원할 날짜의 `inventory-YYYYMMDD.db` 또는
   `pre-reset-날짜-시간.db`를 복사해
   `%LOCALAPPDATA%\CGVGiftDisplay\inventory.db`라는 이름으로 붙여 넣습니다.
4. `start-local.bat`를 실행합니다.

초기화 직전의 최신 내용으로 돌아가려면 가장 최근의 `pre-reset-날짜-시간.db`를
선택합니다. 운영 중인 `inventory.db` 파일만 따로 복사하면 아직 WAL에 있는 변경이
빠질 수 있으므로 위의 검증된 백업 파일을 사용합니다.

## 새 버전으로 업데이트

1. 관리 창을 모두 닫습니다. (이전 버전의 관리 창을 열어 둔 채 계속 수정하면 그
   수정 내용은 저장되지 않습니다.)
2. 새 ZIP을 별도 폴더에 풀고 그 폴더의 `start-local.bat`를 실행합니다. 이전
   버전의 서버가 실행 중이면 자동으로 새 버전으로 교체됩니다.
3. **전시 화면 열기**를 눌러 전시 창을 새 버전으로 다시 엽니다.

데이터 파일은 그대로 이어서 사용합니다. v1.5.0 이하에서 만든 데이터는 처음
실행할 때 자동으로 변환되며 초기화할 필요가 없습니다. 중요한 변경 전에는 위의
방법으로 `inventory.db`를 백업해 두는 것을 권장합니다.

## 문제 해결

- 전시 화면이 잘못된 모니터에 열리면 Windows 디스플레이 모드를 **확장**으로
  설정하고 전시 종료 후 다시 엽니다.
- 브라우저를 찾을 수 없다는 오류는 `browser-settings.json`의 값과 경로를
  확인합니다.
- 화면이 열리지 않으면 `http://127.0.0.1:3210/health`를 브라우저에서 열어
  `"ok": true`가 보이는지 확인합니다.
- 관리 화면에 **데이터를 불러오지 못했습니다**가 계속 표시되면 데이터 파일을
  읽지 못하는 상태입니다. 이 상태에서는 기존 데이터를 보호하기 위해 화면이 열리지
  않습니다. `start-local.bat`를 다시 실행해도 같으면 위의 방법으로 백업에서
  복원합니다.
- 서버 시작 오류는
  `%LOCALAPPDATA%\CGVGiftDisplay\server-error.log`에 기록됩니다.
- PowerShell 실행 자체가 차단됐다는 메시지가 나오면 사내 정책에서
  `powershell.exe`와 로컬 `.ps1` 실행이 허용되는지 담당자에게 확인합니다.
- 데이터만 초기화하려면 `reset-data.bat`, 데이터·백업·전용 브라우저 프로필까지
  지우려면 `clean-uninstall.bat`를 사용합니다.
- 이 PC의 다른 웹사이트는 경품 데이터를 읽거나 바꿀 수 없도록 차단되어 있습니다.

나눔 글꼴은 패키지에 포함되어 오프라인에서도 동일하게 표시됩니다.
